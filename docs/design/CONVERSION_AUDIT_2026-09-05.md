# Homepage conversion audit — value-narrative pass (2026-09-05)

Branch `review/homepage-value-narrative-2026-09-05`, built on the approved Claude Design system from
`review/homepage-claude-design-2026-09-05`. **No visual tokens, components, fonts, colours or the ribbon
Loop were changed.** This is a messaging, information-hierarchy and animated-storytelling pass.

## What changed, and why

| Before (rejected as inside-out) | Now | Why |
|---|---|---|
| Hero lede described the operating system's parts | Hero lede says what the buyer gets: a continuously improving understanding of the event, audience and market; better decisions, sooner; learning carried into the next edition | Benefit-led in the first ten seconds |
| Section 01 "The problem" (a dark, problem-first split) | Section 01 "What you get": the better view, kept current, with the **signal → insight → recommendation → action → result → learning** animation | The positive proposition dominates; the problem is one sentence inside it |
| Section 02 "Connected intelligence" (four signal sources around the Loop) | Section 02 "What the intelligence does": six role-specific examples — Marketing, Content, Sponsorship, Awards, Event Director, Portfolio Director — each as *what Looped saw / what it meant / what changed*, cycling live | Concrete outcomes per buyer instead of an architecture picture; the role tabs are the persona test made visible |
| Section 03 "Understand → Decide → Act → Measure → Learn" (a five-node diagram) | Folded into the signal-loop figure as small labels under the steps | The cycle is still there, shown as intelligence working, not as a process diagram |
| — (absent) | Section 03 "Start anywhere": join the cycle at the brief or eight weeks out; connect deeply, selectively, or begin with the data you have | Removes the "big integration programme" objection; a runner travels the cycle line |
| Section 07 "Portfolio learning" (a stat strip near the bottom) | Section 04 "From one event to the whole business", moved up, with the **one event → next edition → brand → portfolio → organisation** figure and learning arcs travelling between stages | The compounding idea is the central proposition and now has the visual weight to carry it |
| Section 05 "Specialist intelligence" (seven domain rows), Section 09 "Governed autonomy" | Removed as sections; the domains live inside the role examples, governance inside "Trust and control" | Fewer, stronger sections; nothing that reads as an org chart or a control-plane description |
| "Evidence" chain as a seven-node diagram | A one-line record of the chain plus copy about measuring which actions moved bookings, entries, partners and the room | Proof stays; the diagram no longer looks like plumbing |

Locked lines present verbatim: *The art of events is yours. The intelligence is Looped.* · *The AI operating
system for conference & awards businesses* · *AI shouldn't replace the judgement in your business. It should
give that judgement a better view.* · *Time saved isn't the outcome. Better events are.* · *AI should have to
prove its value.* · *Ask · Explore · Instruct* · *Event intelligence that compounds.* · *Your next event
shouldn't start from zero.* · *Every edition should make the next one smarter.*

Nothing on the page names agents, orchestration, memory architecture, graphs, routing or internals.

## Animated storytelling (all stop under reduced motion)

1. **Hero ribbon Loop** — unchanged, the recovered brand animation.
2. **Signal → learning figure** (section 01): dashes travel from four live sources into the Loop, out through
   Insight → Recommendation → Action → Result, and back along the return path labelled "learn · carried into
   the next decision".
3. **Role examples** (section 02): the three columns of each example arrive in sequence; examples rotate every
   5 s and any role can be selected.
4. **Start anywhere** (section 03): a gradient runner travels the event-cycle line; two entry points are marked.
5. **Compounding figure** (section 04): five growing Loops with learning arcs travelling from each stage to the
   next.
